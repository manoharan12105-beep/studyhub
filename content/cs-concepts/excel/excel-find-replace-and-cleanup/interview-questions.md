# Find, Replace and Basic Data Cleanup — Interview Questions

## Beginner

### Q1. What does Remove Duplicates do?

<details>
<summary>Answer</summary>

Data → Remove Duplicates deletes rows that repeat, keeping the first occurrence of each. You choose the columns that define a duplicate — with Emp ID ticked, two rows with the same ID count as duplicates. Excel then reports how many duplicates were removed and how many unique values remain. Because it deletes rows, check the columns carefully or work on a copy.

</details>

### Q2. What is the difference between Find and Replace?

<details>
<summary>Answer</summary>

Find (Ctrl + F) only locates matches — Find Next jumps to each, Find All lists them. Replace (Ctrl + H) also changes them, one at a time or with Replace All. Both have options such as Match case, Match entire cell contents and searching the whole workbook.

</details>

## Intermediate

### Q3. What is Freeze Panes and when would you use it?

<details>
<summary>Answer</summary>

View → Freeze Panes keeps chosen rows and columns visible while the rest of the sheet scrolls. On a long list, Freeze Top Row keeps the headings in view; selecting B2 and choosing Freeze Panes keeps both row 1 and column A (for example, names) visible. It changes only the view, not the data.

</details>
