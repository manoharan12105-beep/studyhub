# Find, Replace and Basic Data Cleanup — Practice

### P1. Fix a spelling everywhere

**Difficulty:** Easy · **Type:** Shortcut · **Concepts:** replace

Department names were typed as `Mech` in 40 rows and must become `MECH`. Which shortcut opens the right tool?

- A) Ctrl + F
- B) Ctrl + H
- C) Ctrl + T
- D) Ctrl + P

<details>
<summary>Answer</summary>

**Answer:** B) Ctrl + H

Ctrl + H opens Find and Replace on the Replace tab; Replace All changes every match.

</details>

### P2. How many remain?

**Difficulty:** Medium · **Type:** Scenario · **Concepts:** remove duplicates

An ID column contains E1, E2, E3, E2, E4, E1, E5 (with a header). You run Remove Duplicates on it. How many IDs remain?

- A) 7
- B) 5
- C) 3
- D) 2

<details>
<summary>Answer</summary>

**Answer:** B) 5

E1, E2, E3, E4 and E5 — the second E2 and second E1 are removed.

</details>

### P3. Split full names

**Difficulty:** Easy · **Type:** MCQ · **Concepts:** text to columns

Column A contains full names like `Divya Kumar`. Which feature splits them into first and last name columns?

- A) Freeze Panes
- B) Text to Columns with Space as delimiter
- C) Remove Duplicates
- D) Merge & Center

<details>
<summary>Answer</summary>

**Answer:** B) Text to Columns with Space as delimiter

Delimited splitting at the space puts the first name in A and the last name in B.

</details>
