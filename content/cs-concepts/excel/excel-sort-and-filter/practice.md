# Sort and Filter — Practice

### P1. Show only some rows

**Difficulty:** Easy · **Type:** Scenario · **Concepts:** filter

Your manager wants to see only the South region's sales, without deleting anything. Which feature do you use?

- A) Sort
- B) Filter
- C) Remove Duplicates
- D) Find

<details>
<summary>Answer</summary>

**Answer:** B) Filter

Filter hides rows that do not match (Region = South) and keeps all data.

</details>

### P2. Top performers first

**Difficulty:** Easy · **Type:** Scenario · **Concepts:** sort

You want the student with the highest marks at the top of the list. What do you do?

- A) Sort the Marks column Smallest to Largest
- B) Sort the Marks column Largest to Smallest
- C) Filter Marks Greater Than 50
- D) Sort the Name column A to Z

<details>
<summary>Answer</summary>

**Answer:** B) Sort the Marks column Largest to Smallest

Descending order puts 91 (Divya) at the top. A filter would hide rows rather than order them.

</details>

### P3. Count the rows

**Difficulty:** Medium · **Type:** Scenario · **Concepts:** number filter

On the Sales sheet (sales: 50000, 30000, 45000, 35000, 52000, 28000, 47000, 36000, 55000, 33000, 44000, 40000), you apply Number Filters → Greater Than → 40000. How many rows are shown?

- A) 5
- B) 6
- C) 7
- D) 12

<details>
<summary>Answer</summary>

**Answer:** B) 6

50000, 45000, 52000, 47000, 55000 and 44000. The value 40000 is not *greater than* 40000; "Greater Than Or Equal To" would show 7.

</details>
