# Essential Excel Keyboard Shortcuts — Interview Questions

## Beginner

### Q1. What do Ctrl + C, Ctrl + V and Ctrl + Z do?

<details>
<summary>Answer</summary>

Ctrl + C copies the selected cells, Ctrl + V pastes them, and Ctrl + Z undoes the last action (pressing it again undoes earlier actions). Ctrl + X cuts (moves) and Ctrl + Y redoes what was undone.

</details>

### Q2. What do Ctrl + F and Ctrl + H do?

<details>
<summary>Answer</summary>

Ctrl + F opens Find to locate text or numbers in the sheet or workbook. Ctrl + H opens the same dialog on the Replace tab, to change matches one by one or all at once with Replace All.

</details>

## Intermediate

### Q3. What do F2 and Alt + = do?

<details>
<summary>Answer</summary>

F2 puts the active cell into edit mode with the cursor at the end of its content, so you can change part of a value or formula without retyping it. Alt + = is AutoSum: it inserts `=SUM(...)` with the range of numbers directly above (or to the left), ready to confirm with Enter.

</details>
