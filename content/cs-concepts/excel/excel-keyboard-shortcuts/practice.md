# Essential Excel Keyboard Shortcuts — Practice

### P1. Undo

**Difficulty:** Easy · **Type:** Shortcut · **Concepts:** undo

You accidentally deleted a row. Which shortcut brings it back immediately?

- A) Ctrl + Y
- B) Ctrl + Z
- C) Ctrl + D
- D) Ctrl + S

<details>
<summary>Answer</summary>

**Answer:** B) Ctrl + Z

Undo reverses the last action. Ctrl + Y redoes an undone action.

</details>

### P2. Edit a cell

**Difficulty:** Easy · **Type:** Shortcut · **Concepts:** F2

Which key lets you edit the formula in the active cell without retyping it?

- A) F2
- B) F4
- C) F11
- D) Esc

<details>
<summary>Answer</summary>

**Answer:** A) F2

F2 opens the cell for editing. F4 toggles `$` in a reference while editing; Esc cancels.

</details>

### P3. Quick total

**Difficulty:** Easy · **Type:** Shortcut · **Concepts:** AutoSum

You select the empty cell below a column of salaries. Which shortcut inserts a SUM formula for the column above?

- A) Ctrl + =
- B) Alt + =
- C) Ctrl + Shift + S
- D) Ctrl + T

<details>
<summary>Answer</summary>

**Answer:** B) Alt + =

Alt + = is AutoSum; press Enter to confirm the suggested range.

</details>
