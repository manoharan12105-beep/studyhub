# Basic Charts — Interview Questions

## Beginner

### Q1. When should you use a line chart?

<details>
<summary>Answer</summary>

When showing how a value changes over time — monthly sales, daily attendance, yearly revenue. The points are joined in time order, so the slope shows whether the value is rising or falling. For comparisons between unrelated categories, a column or bar chart is clearer.

</details>

### Q2. When should you use a column chart, and how is it different from a bar chart?

<details>
<summary>Answer</summary>

A column chart compares values across categories with vertical bars — for example, total sales by product. A bar chart does the same with horizontal bars; it is better when category names are long or there are many categories, because the labels have room on the left. The choice between them is mostly about readability.

</details>

### Q3. When is a pie chart appropriate?

<details>
<summary>Answer</summary>

When showing how one whole is divided into parts — for example, each product's share of total sales. It works only with a single series, a few categories (about five or fewer) and positive values that add up to a meaningful total. It is a poor choice for trends over time or for comparing many similar values.

</details>
