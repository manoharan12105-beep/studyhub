# Excel Tables — Practice

### P1. Create a Table

**Difficulty:** Easy · **Type:** Shortcut · **Concepts:** create table

Which shortcut converts the selected list into an Excel Table?

- A) Ctrl + T
- B) Ctrl + Shift + L
- C) Alt + =
- D) Ctrl + H

<details>
<summary>Answer</summary>

**Answer:** A) Ctrl + T

Ctrl + Shift + L only toggles filter buttons; it does not create a Table.

</details>

### P2. Adding a row

**Difficulty:** Easy · **Type:** Scenario · **Concepts:** table expansion

The Sales Table covers A1:D13. You type a new record directly in row 14. What happens?

- A) Nothing — you must recreate the Table
- B) The Table expands to A1:D14 and formats the new row
- C) Excel shows an error
- D) Row 14 is added only after you save

<details>
<summary>Answer</summary>

**Answer:** B) The Table expands to A1:D14 and formats the new row

Typing directly below a Table extends it automatically.

</details>

### P3. Total of visible rows

**Difficulty:** Medium · **Type:** Scenario · **Concepts:** total row, filter

The Sales Table has a Total Row showing Sum of Sales = 495000. You filter Product = Laptop (Laptop sales: 50000, 45000, 52000, 47000, 55000, 44000). What does the Total Row show now?

- A) 495000
- B) 293000
- C) 202000
- D) 0

<details>
<summary>Answer</summary>

**Answer:** B) 293000

The Total Row adds only visible rows: 50000 + 45000 + 52000 + 47000 + 55000 + 44000 = 293000.

</details>
