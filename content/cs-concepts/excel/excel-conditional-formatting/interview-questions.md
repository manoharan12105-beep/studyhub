# Conditional Formatting — Interview Questions

## Beginner

### Q1. What is conditional formatting? Give an example.

<details>
<summary>Answer</summary>

Conditional formatting applies formatting automatically to cells that meet a rule based on their values. For example, Home → Conditional Formatting → Highlight Cells Rules → Less Than 40 on a marks column turns failing marks red. If a mark is corrected to 48, the red disappears by itself, unlike manual formatting.

</details>

## Intermediate

### Q2. How would you find duplicate employee IDs in a column?

<details>
<summary>Answer</summary>

Select the ID column and apply Home → Conditional Formatting → Highlight Cells Rules → Duplicate Values. Every repeated ID is highlighted, including the first occurrence, so you can inspect the rows before deciding what to do. To delete the duplicate rows afterwards, use Data → Remove Duplicates.

</details>
