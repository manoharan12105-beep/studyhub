# Conditional Formatting — Practice

### P1. Highlight high salaries

**Difficulty:** Easy · **Type:** Scenario · **Concepts:** highlight cells rules

You want every salary above 50000 to turn green automatically, and to update if salaries change. What do you use?

- A) Fill colour on each cell
- B) Conditional Formatting → Highlight Cells Rules → Greater Than
- C) Filter → Number Filters → Greater Than
- D) Sort Largest to Smallest

<details>
<summary>Answer</summary>

**Answer:** B) Conditional Formatting → Highlight Cells Rules → Greater Than

It formats cells by value and updates automatically. A filter would hide the other rows instead of highlighting.

</details>

### P2. Which cells turn red?

**Difficulty:** Medium · **Type:** Scenario · **Concepts:** less than, boundary

Marks are 82, 45, 40, 67, 39. The rule is Highlight Cells Rules → Less Than → 40. Which marks are highlighted?

- A) 39 only
- B) 39 and 40
- C) 40, 39 and 45
- D) None

<details>
<summary>Answer</summary>

**Answer:** A) 39 only

"Less Than 40" is strict; 40 is not less than 40.

</details>

### P3. See every value's size

**Difficulty:** Easy · **Type:** MCQ · **Concepts:** data bars, color scales

You want each Sales cell to show a bar whose length matches its value. Which option do you choose?

- A) Duplicate Values
- B) Data Bars
- C) Equal To
- D) Freeze Panes

<details>
<summary>Answer</summary>

**Answer:** B) Data Bars

Data Bars draw an in-cell bar proportional to the value. Color Scales would shade the cells instead.

</details>
