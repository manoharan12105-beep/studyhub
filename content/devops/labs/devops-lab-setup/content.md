# Lab Setup and the Sample Application

**Labs:** Setup · **Module:** Practical Labs · **Verification:** Tested (application code)

## What Is It?

The eighteen labs of this subject build one real project step by step — the **Task API**, a Spring Boot + PostgreSQL REST service — from a first container to an automated, HTTPS-secured production deployment. This page lists the tools you need, explains how labs are written, and contains the **complete source** of the application.

> [!IMPORTANT]
> **Run this on your machine or server.** StudyHub is a static website: it never runs Docker, connects to servers or deploys anything. Interactive boxes inside lessons are clearly titled as *simulations*; everything in a lab is something **you** run in your own terminal.

## How Labs Are Written

Every lab has the same sections: **Objective**, **Prerequisites**, **Scenario**, **Steps** (commands, the expected result and an explanation for each), **Verification Checklist**, **Common Mistakes** and **Troubleshooting**; its interview questions are on the lab's *Interview questions* tab.

Each lab states how it was verified when it was written:

| Label | Meaning |
|-------|---------|
| **Tested** | Every command and every `**Output:**` block was run and captured. |
| **Partly tested** | The parts named in the lab's note were really run (for example the Java code, the Maven build, a config syntax check); the rest is instruction only. |
| **Instruction only** | Written from the tools' documented behaviour and checked for syntax where possible, but not executed — Docker was not available in the authoring environment, and no VPS, domain or GitHub repository was used. Results are described as **Expected result**, never as captured output. |

Blocks marked `# Illustrative` need Docker, root access, a network or a server.

## The Task API

| Endpoint | Behaviour |
|----------|-----------|
| `GET /api/tasks` | All tasks, ordered by id |
| `POST /api/tasks` | Create from `{"title":"…"}`; `201` with the task, `400` if the title is blank |
| `GET /api/info` | `app`, `version`, active `profiles`, `host` |
| `GET /actuator/health`, `/liveness`, `/readiness` | Health for people, Docker and scripts |

Stack: Java 21, Spring Boot 4.1 (Spring Web MVC, Spring Data JPA, Validation, Actuator, Flyway), PostgreSQL JDBC driver.

**Verification:** the project below was built with Maven (`./mvnw -B verify`, all 3 tests passing) against PostgreSQL 18 and run with the `prod` profile; every response quoted in the lessons came from it. Docker was not used for these runs.

package com.example.taskapi.task;

import jakarta.persistence.Entity;
import jakarta.persistence.GeneratedValue;
import jakarta.persistence.GenerationType;
import jakarta.persistence.Id;
import jakarta.persistence.Table;

@Entity
@Table(name = "tasks")
public class Task {

    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long id;

    private String title;

    private boolean done;

    protected Task() {
        // for JPA
    }

    public Task(String title) {
        this.title = title;
    }

    public Long getId() { return id; }
    public String getTitle() { return title; }
    public boolean isDone() { return done; }
}

`src/main/java/com/example/taskapi/task/TaskController.java`:

```java
package com.example.taskapi.task;

import jakarta.validation.Valid;
import java.util.List;
import org.slf4j.Logger;
import org.slf4j.LoggerFactory;
import org.springframework.data.domain.Sort;
import org.springframework.http.HttpStatus;
import org.springframework.web.bind.annotation.GetMapping;
import org.springframework.web.bind.annotation.PostMapping;
import org.springframework.web.bind.annotation.RequestBody;
import org.springframework.web.bind.annotation.RequestMapping;
import org.springframework.web.bind.annotation.ResponseStatus;
import org.springframework.web.bind.annotation.RestController;

@RestController
@RequestMapping("/api/tasks")
public class TaskController {

    private static final Logger log = LoggerFactory.getLogger(TaskController.class);

    private final TaskRepository tasks;

    public TaskController(TaskRepository tasks) {
        this.tasks = tasks;
    }

    @GetMapping
    public List<Task> list() {
        return tasks.findAll(Sort.by("id"));
    }

    @PostMapping
    @ResponseStatus(HttpStatus.CREATED)
    public Task create(@Valid @RequestBody CreateTaskRequest request) {
        Task saved = tasks.save(new Task(request.title()));
        log.info("Created task {}", saved.getId());
        return saved;
    }
}
```

`src/main/java/com/example/taskapi/info/InfoController.java`:

```java
package com.example.taskapi.info;

import java.net.InetAddress;
import java.net.UnknownHostException;
import java.util.LinkedHashMap;
import java.util.Map;
import org.springframework.beans.factory.annotation.Value;
import org.springframework.core.env.Environment;
import org.springframework.web.bind.annotation.GetMapping;
import org.springframework.web.bind.annotation.RestController;

@RestController
public class InfoController {

    private final Environment environment;
    private final String version;

    public InfoController(Environment environment, @Value("${app.version:dev}") String version) {
        this.environment = environment;
        this.version = version;
    }

    // Shows which build, profile and host answered: the first check after every deployment.
    @GetMapping("/api/info")
    public Map<String, String> info() throws UnknownHostException {
        Map<String, String> info = new LinkedHashMap<>();
        info.put("app", "taskapi");
        info.put("version", version);
        info.put("profiles", String.join(",", environment.getActiveProfiles()));
        info.put("host", InetAddress.getLocalHost().getHostName());
        return info;
    }
}

package com.example.taskapi;

import org.springframework.beans.factory.annotation.Value;
import org.springframework.context.annotation.Configuration;
import org.springframework.web.servlet.config.annotation.CorsRegistry;
import org.springframework.web.servlet.config.annotation.WebMvcConfigurer;

@Configuration
public class CorsConfig implements WebMvcConfigurer {

    // Comma-separated list, e.g. APP_CORS_ALLOWED_ORIGINS=https://app.example.com
    @Value("${app.cors.allowed-origins:http://localhost:5173}")
    private String[] allowedOrigins;

    @Override
    public void addCorsMappings(CorsRegistry registry) {
        registry.addMapping("/api/**")
                .allowedOrigins(allowedOrigins)
                .allowedMethods("GET", "POST", "PUT", "DELETE");
    }
}
```

## Source: Configuration and Migration

`src/main/resources/application.yml`:

```yaml
spring:
  application:
    name: taskapi
  datasource:
    # Local development defaults. Every other environment overrides them with
    # SPRING_DATASOURCE_URL, SPRING_DATASOURCE_USERNAME and SPRING_DATASOURCE_PASSWORD.
    url: jdbc:postgresql://localhost:5432/taskdb
    username: taskapp
    password: dev-only-password
  jpa:
    open-in-view: false
    hibernate:
      ddl-auto: validate

management:
  endpoints:
    web:
      exposure:
        include: health,info
  endpoint:
    health:
      probes:
        enabled: true
      group:
        readiness:
          # By default readiness reflects only the application's own state;
          # adding db makes "ready" also mean "the database answers".
          include: readinessState,db
```

`dev-only-password` is a deliberately public value for a local development database only; production never uses it because `application-prod.yml` replaces it.

`src/main/resources/application-prod.yml`:

## Source: Test

`src/test/java/com/example/taskapi/TaskApiApplicationTests.java`:

```java
package com.example.taskapi;

import static org.springframework.test.web.servlet.request.MockMvcRequestBuilders.get;
import static org.springframework.test.web.servlet.request.MockMvcRequestBuilders.post;
import static org.springframework.test.web.servlet.result.MockMvcResultMatchers.jsonPath;
import static org.springframework.test.web.servlet.result.MockMvcResultMatchers.status;

import org.junit.jupiter.api.Test;
import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.boot.test.context.SpringBootTest;
import org.springframework.boot.webmvc.test.autoconfigure.AutoConfigureMockMvc;
import org.springframework.http.MediaType;
import org.springframework.test.web.servlet.MockMvc;

// Needs a running PostgreSQL: locally the defaults in application.yml,
// in CI a service container configured through SPRING_DATASOURCE_* variables.
@SpringBootTest
@AutoConfigureMockMvc
class TaskApiApplicationTests {

    @Autowired
    MockMvc mvc;

    @Test
    void createsAndListsTasks() throws Exception {
        mvc.perform(post("/api/tasks")
                        .contentType(MediaType.APPLICATION_JSON)
                        .content("{\"title\":\"Write Dockerfile\"}"))
                .andExpect(status().isCreated())
                .andExpect(jsonPath("$.title").value("Write Dockerfile"))
                .andExpect(jsonPath("$.done").value(false));

        mvc.perform(get("/api/tasks"))
                .andExpect(status().isOk())
                .andExpect(jsonPath("$[?(@.title == 'Write Dockerfile')]").exists());
    }

    @Test
    void rejectsBlankTitle() throws Exception {
        mvc.perform(post("/api/tasks")
                        .contentType(MediaType.APPLICATION_JSON)
                        .content("{\"title\":\"\"}"))
                .andExpect(status().isBadRequest());
    }

    @Test
    void healthIsUp() throws Exception {
        mvc.perform(get("/actuator/health"))
                .andExpect(status().isOk())
                .andExpect(jsonPath("$.status").value("UP"));
    }
}
```
