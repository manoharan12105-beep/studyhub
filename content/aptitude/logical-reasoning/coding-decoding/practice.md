# Coding-Decoding — Practice

### P1. If BOOK is coded as CPPL, how is PEN coded?

**Difficulty:** Easy · **Pattern:** Constant shift

- A) OFM
- B) QFO
- C) QEO
- D) RGP

<details>
<summary>Answer</summary>

**Answer:** B) QFO

**Explanation:** Each letter +1: P → Q, E → F, N → O.

</details>

### P3. In a code, each letter is replaced by its opposite letter (A ↔ Z, B ↔ Y, …). How is CAT coded?

**Difficulty:** Easy · **Pattern:** Opposite letters

- A) XZG
- B) DBU
- C) XZH
- D) YZG

<details>
<summary>Answer</summary>

**Answer:** A) XZG

**Explanation:** C (3) ↔ X (24), A ↔ Z, T (20) ↔ G (7).

</details>

### P4. If ACE = 9, what is BAG?

**Difficulty:** Medium · **Pattern:** Number coding

- A) 9
- B) 10
- C) 11
- D) 14

<details>
<summary>Answer</summary>

**Answer:** B) 10

**Explanation:** ACE = 1 + 3 + 5 = 9 → sum of positions. BAG = 2 + 1 + 7 = 10.

</details>

### P5. If FRIEND is coded as HUMJTK, how is CANDLE coded?

**Difficulty:** Medium · **Pattern:** Changing shift

- A) EDRIRL
- B) DCQHQK
- C) EDRJRL
- D) ESJKTE

<details>
<summary>Hint</summary>

Find the shift for each letter separately.

</details>

<details>
<summary>Answer</summary>

**Answer:** A) EDRIRL

**Explanation:** FRIEND → HUMJTK uses shifts +2, +3, +4, +5, +6, +7. CANDLE: C + 2 = E, A + 3 = D, N + 4 = R, D + 5 = I, L + 6 = R, E + 7 = L.

</details>

### P6. If PRINCE is coded as QQJMDD, how is FRIEND coded?

**Difficulty:** Medium · **Pattern:** Alternating shift

- A) GSJFOE
- B) GQJDOC
- C) EQHDMC
- D) GQJDOE

<details>
<summary>Answer</summary>

**Answer:** B) GQJDOC

**Explanation:** PRINCE → QQJMDD alternates +1, −1: P+1, R−1, I+1, N−1, C+1, E−1. FRIEND → F+1 = G, R−1 = Q, I+1 = J, E−1 = D, N+1 = O, D−1 = C.

</details>

### P7. In a code language, "good boy run" is "ki lo pa", "run fast now" is "pa ze mu", and "now good food" is "ki mu ro". What is the code for "boy"?

**Difficulty:** Medium · **Pattern:** Sentence coding

- A) ki
- B) lo
- C) pa
- D) mu

<details>
<summary>Answer</summary>

**Answer:** B) lo

**Explanation:** "run" is in sentences 1 and 2 → pa. "good" is in 1 and 3 → ki. Sentence 1 is good (ki), boy, run (pa) → boy = lo.

</details>

### P8. If MONKEY is coded as XDJMNL, how is TIGER coded?

**Difficulty:** Hard · **Pattern:** Reverse and shift

- A) SHFDQ
- B) QDFHS
- C) UJHFS
- D) RFHJU

<details>
<summary>Answer</summary>

**Answer:** B) QDFHS

**Explanation:** Reverse the word, then shift each letter −1. MONKEY → YEKNOM → XDJMNL. TIGER → REGIT → QDFHS. Option A shifts without reversing.

</details>

### P10. In a code language, "pen is red" is "lo ma pi", "red and blue" is "ma tu ka", and "blue pen sold" is "pi ka zo". Which code means "and"?

**Difficulty:** Hard · **Pattern:** Sentence coding

- A) ma
- B) ka
- C) tu
- D) Cannot be determined

<details>
<summary>Answer</summary>

**Answer:** C) tu

**Explanation:** red (1 & 2) = ma; blue (2 & 3) = ka; pen (1 & 3) = pi. Sentence 2 is red (ma), and, blue (ka) → and = tu.

</details>
