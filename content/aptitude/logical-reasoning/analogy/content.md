# Analogy

## Concept

An **analogy** compares two pairs that share the same relationship: *Doctor : Hospital :: Teacher : School* reads "doctor is to hospital as teacher is to school". The first pair shows a relationship; you must find the item that creates **the same relationship** in the second pair.

The key skill is naming the relationship precisely. "Doctor works in a hospital" is precise; "doctor is related to hospital" is too vague and lets several options fit.

## Rules

### Common word relationships

| Relationship | Example |
|--------------|---------|
| Worker : Workplace | Doctor : Hospital |
| Worker : Tool | Carpenter : Saw |
| Tool : Function | Pen : Write |
| Organ : Function | Eye : See |
| Animal : Young one | Cow : Calf |
| Animal / creature : Home | Bee : Hive |
| Individual : Group | Soldier : Army |
| Product : Raw material | Paper : Tree (wood) |
| Instrument : What it measures | Thermometer : Temperature |
| Synonym | Brave : Courageous |
| Antonym | Ascend : Descend |
| Part : Whole | Page : Book |
| Cause : Effect | Fire : Smoke |

### Number analogies

The second number is obtained from the first by an operation: square (5 : 25), cube (3 : 27), square ± 1 (6 : 35), cube ± 1 (2 : 9), multiple (4 : 12).

### Letter analogies

Letters are shifted by a fixed amount (CAT : DBU, +1), reversed, or replaced by opposite letters — the same rules as [Coding-Decoding](../coding-decoding/content.md).

## Solving Approach

1. Make a short, specific sentence linking the first pair: "A ___ B".
2. Apply the same sentence to the second pair, with the same **direction** (if the first pair is worker : tool, the second must also be worker : tool, not tool : worker).
3. If two options fit, make the sentence more specific.
4. For numbers, test squares, cubes, ±1, and multiples before more complex rules.

## Problem Patterns

### Pattern 1: Complete the analogy

**Example:** Pen : Write :: Knife : ? → tool : function → **Cut**.

### Pattern 2: Choose the analogous pair

**Recognise it:** a pair is given; choose the option pair with the same relationship.

**Example:** Carpenter : Saw → worker : tool → **Farmer : Plough** (not "Farmer : Field", which is worker : workplace).

### Pattern 3: Number analogy

**Example:** 6 : 35 :: 8 : ? → 6² − 1 = 35 → 8² − 1 = **63**.

### Pattern 4: Letter analogy

**Example:** ACE : BDF :: GIK : ? → each letter +1 → **HJL**.

## Common Mistakes

- Using a vague relationship that fits several options.
- Reversing the direction of the relationship in the second pair.
- Choosing a word that is merely associated with the second item rather than in the same relationship.
- For number analogies, stopping at the first operation that fits one pair without checking it is the simplest.

## Placement Tips

- Say the relationship as a sentence in your head — it is faster than it sounds and prevents vague matches.
- Eliminate options that are associated but have the wrong relationship type.
- Number analogies are usually squares, cubes or their neighbours; check those first.

## Key Takeaways

- Name the relationship precisely; keep its direction.
- Common relationships: worker–tool/workplace, tool–function, animal–young/home, individual–group, product–raw material, instrument–measure, synonym, antonym.
- Number analogies: squares, cubes, ±1; letter analogies: shifts and reversals.
