# Classification — Practice

### P1. Delhi, Paris, Tokyo. Which option belongs to the same group?

**Difficulty:** Easy · **Pattern:** Word classification

- A) Mumbai
- B) Sydney
- C) Canberra
- D) New York

<details>
<summary>Answer</summary>

**Answer:** C) Canberra

**Explanation:** The given cities are national capitals. Canberra is the capital of Australia; Sydney, Mumbai and New York are large cities but not national capitals.

</details>

### P3. 4, 16, 36. Which option belongs to the same group?

**Difficulty:** Easy · **Pattern:** Number classification

- A) 25
- B) 49
- C) 64
- D) 81

<details>
<summary>Answer</summary>

**Answer:** C) 64

**Explanation:** The given numbers are even perfect squares (2², 4², 6²). 64 = 8² is the only even square among the options.

</details>

### P6. 3, 5, 7. Which option belongs to the same group?

**Difficulty:** Medium · **Pattern:** Number classification

- A) 9
- B) 15
- C) 11
- D) 21

<details>
<summary>Answer</summary>

**Answer:** C) 11

**Explanation:** The given numbers are primes. 9 = 3², 15 = 3 × 5, 21 = 3 × 7 are composite.

</details>

### P7. AC, EG, IK. Which option belongs to the same group?

**Difficulty:** Medium · **Pattern:** Letter classification

- A) MO
- B) OQ
- C) UX
- D) BD

<details>
<summary>Answer</summary>

**Answer:** B) OQ

**Explanation:** Each pair starts with a vowel (A, E, I) and skips one letter. OQ starts with the vowel O and skips P. MO and BD start with consonants; UX skips two letters.

</details>

### P9. 121, 484, 676. Which option belongs to the same group?

**Difficulty:** Hard · **Pattern:** Number classification

- A) 169
- B) 252
- C) 10201
- D) 441

<details>
<summary>Hint</summary>

Read each number backwards.

</details>

<details>
<summary>Answer</summary>

**Answer:** C) 10201

**Explanation:** The given numbers are perfect squares that are also palindromes (11², 22², 26²). 10201 = 101² and reads the same backwards. 169 and 441 are squares but not palindromes; 252 is a palindrome but not a square.

</details>

### P10. BDF, HJL, NPR. Which option belongs to the same group?

**Difficulty:** Hard · **Pattern:** Letter classification

- A) TVX
- B) SUW
- C) CEH
- D) KMP

<details>
<summary>Answer</summary>

**Answer:** A) TVX

**Explanation:** Positions 2-4-6, 8-10-12, 14-16-18: three consecutive even positions. TVX = 20-22-24. SUW = 19-21-23 (odd); CEH and KMP have unequal gaps.

</details>
