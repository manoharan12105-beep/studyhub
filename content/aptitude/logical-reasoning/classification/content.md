# Classification

## Concept

**Classification** means grouping items by a property they share. A classification question shows a few items that form a class and asks which option **belongs to the same class** — or asks you to recognise the basis on which items have been grouped.

The skill is finding the **most specific** property shared by the given items. "Apple, Mango, Banana" share "plant products", "food" and "fruits"; only "fruits" is specific enough to select one option and reject the rest.

Classification is the positive side of [Odd One Out](../odd-one-out/content.md): there you find the item that breaks the class; here you find the item that fits it. The same bases of classification are used in both.

## Rules

### Bases of classification

| Basis | Example class |
|-------|---------------|
| Category | Fruits, metals, planets, capital cities, currencies |
| Function or use | Measuring instruments, wind instruments, units of mass |
| Composition | Pure metals vs alloys (brass, bronze, steel) |
| Habitat or origin | Aquatic animals, desert plants |
| Number property | Primes, perfect squares, odd squares, multiples of 7, palindromes |
| Letter pattern | Vowel-started pairs, fixed gaps, letters following each vowel |

### The specificity rule

List every property the given items share, from broad to narrow. Choose the narrowest property that **exactly one** option satisfies.

**Example:** 9, 25, 49 → all squares, all **odd** squares. Options 16, 36, 81, 100 are all squares, but only 81 is an odd square → 81.

## Solving Approach

1. Name what the given items have in common (category, function, number or letter property).
2. Make the property more specific until exactly one option fits.
3. Check that the chosen option fits **every** part of the property and the other options fail at least one part.

## Problem Patterns

### Pattern 1: Word classification

**Example:** Copper, Iron, Silver → pure metals. Options: Brass, Bronze, Steel, Zinc → brass, bronze and steel are alloys → **Zinc**.

### Pattern 2: Number classification

**Example:** 13, 31, 17, 71 → primes whose digit-reversal is also prime. Options: 19 (91 = 7 × 13), 37 (73 prime ✓), 23 (32), 29 (92) → **37**.

### Pattern 3: Letter classification

**Example:** BCD, FGH, JKL → the three letters after each vowel (A, E, I). The next vowel is O → **PQR**.

## Common Mistakes

- Stopping at a broad property that several options satisfy.
- Using a property only some of the given items share.
- Missing composition differences (alloy vs pure metal, mammal vs fish) that question setters rely on.

## Placement Tips

- If two options seem to fit, the class is more specific than you think — look again at the given items.
- For numbers, test: prime, square, cube, odd/even, divisibility, digit sum, palindrome.
- For letters, convert to positions and check gaps and vowels.

## Key Takeaways

- Find the most specific property that all given items share.
- Exactly one option should satisfy it.
- Classification and odd-one-out use the same bases; one finds the fit, the other the misfit.
