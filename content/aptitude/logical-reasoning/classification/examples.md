# Classification — Solved Examples

### E1. Category

**Difficulty:** Easy · **Pattern:** Word classification

**Problem:** Apple, Mango, Banana. Which option belongs to the same group? A) Potato B) Rose C) Grape D) Carrot

**Solution:**

1. The given items are fruits.
2. Potato and carrot are vegetables; rose is a flower; grape is a fruit.

**Answer:** **C) Grape**

### E2. Specific number property

**Difficulty:** Medium · **Pattern:** Number classification

**Problem:** 9, 25, 49. Which option belongs to the same group? A) 16 B) 36 C) 81 D) 100

**Solution:**

1. All three are perfect squares — but every option is a square too.
2. More specific: they are **odd** squares (3², 5², 7²).
3. Only 81 = 9² is an odd square.

**Answer:** **C) 81**

### E3. Composition

**Difficulty:** Medium · **Pattern:** Word classification

**Problem:** Copper, Iron, Silver. Which option belongs to the same group? A) Brass B) Bronze C) Steel D) Zinc

**Solution:**

1. All options are metals, so "metal" is too broad.
2. Copper, iron and silver are pure metallic elements; brass, bronze and steel are alloys (mixtures).
3. Zinc is a pure metallic element.

**Answer:** **D) Zinc**

### E4. Letter pattern

**Difficulty:** Hard · **Pattern:** Letter classification

**Problem:** BCD, FGH, JKL. Which option belongs to the same group? A) MNO B) PQR C) NPQ D) STU

**Solution:**

1. BCD follows A; FGH follows E; JKL follows I — each group is the three letters right after a vowel.
2. The next vowel is O → PQR.
3. MNO contains a vowel and does not follow one; NPQ is not consecutive; STU contains U.

**Answer:** **B) PQR**

### E5. Combined number property

**Difficulty:** Hard · **Pattern:** Number classification

**Problem:** 13, 31, 17, 71. Which option belongs to the same group? A) 19 B) 37 C) 23 D) 29

**Solution:**

1. All are primes, and so are all the options — too broad.
2. Each given prime reversed is also prime: 13 ↔ 31, 17 ↔ 71.
3. Reverse the options: 91 = 7 × 13 ✗; 73 prime ✓; 32 ✗; 92 ✗.

**Answer:** **B) 37**
