# Odd One Out

## Concept

An **odd-one-out** question lists four or five items; all but one share a property. You must find the one that does not. It uses the same bases as [Classification](../classification/content.md) — category, function, composition, number and letter properties — but the task is reversed: find the **misfit**.

The difficulty is that items usually differ in many small ways. A good answer rests on a property that is:

1. **Shared by all the others**, and
2. **Meaningful** — category, structure or mathematical property, not a surface feature like word length (unless nothing else works).

## Rules

### Common bases

| Type | Typical property tested | Example (odd item in bold) |
|------|-------------------------|----------------------------|
| Words | Category, function, habitat | Mercury, Venus, **Moon**, Mars |
| Word pairs | Same relationship in each pair | Car : Garage, Horse : Stable, **Ship : Sea** |
| Numbers | Prime, square, cube, multiple, odd/even | 2, 3, 5, **9**, 11 |
| Letters | Equal gaps, vowel positions, reversals | BD, FH, JL, **NQ** |

### When two items seem odd

Sometimes two different properties each isolate a different item. Prefer the property that:

- is mathematical or categorical rather than cosmetic,
- applies uniformly to all the remaining items,
- leaves **exactly one** odd item.

## Solving Approach

1. Look for the broad category first (are they all fruits? all primes?).
2. If all share the category, look one level deeper (composition, family, habitat, sub-type).
3. For numbers, test: prime, square, cube, multiple, digit sum, odd/even.
4. For letters, convert to positions and check gaps.
5. For pairs, state each pair's relationship in a sentence; the odd pair has a different sentence.
6. Confirm the chosen property is shared by **all** the other items.

## Problem Patterns

### Pattern 1: Category misfit

**Example:** Tiger, Lion, Cheetah, Wolf → all are predators, but tiger, lion and cheetah belong to the cat family → **Wolf**.

### Pattern 2: Number property

**Example:** 8, 27, 64, 100, 125 → cubes of 2, 3, 4, 5 except **100**.

### Pattern 3: Letter gaps

**Example:** AEI, BFJ, CGK, DHM → each group goes +4, +4 except DHM (D → H is +4, H → M is +5) → **DHM**.

### Pattern 4: Pair relationship

**Example:** Car : Garage, Aeroplane : Hangar, Horse : Stable, Ship : Sea → each pair is "kept in/sheltered in" except **Ship : Sea** (where it travels; a ship is kept in a dock).

## Common Mistakes

- Choosing an item for a cosmetic reason (number of letters, starting letter) when a meaningful property exists.
- Picking a property that some of the "regular" items also fail.
- Not checking every item, especially in five-item questions.

## Placement Tips

- Give each question about 20 seconds; if two properties compete, use the specificity rule above.
- In number sets, quickly mark primes and squares — they cover most questions.
- In letter sets, write the position gaps; the odd group usually breaks one gap.

## Key Takeaways

- The odd item fails a property that all others share.
- Prefer meaningful properties (category, structure, maths) over surface features.
- Check that the property isolates exactly one item.
