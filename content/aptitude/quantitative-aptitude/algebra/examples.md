# Algebra — Solved Examples

### E1. Linear equation in one variable

**Difficulty:** Easy · **Pattern:** Linear Equations

**Problem:** Solve 3x + 7 = 22.

**Solution:**

1. Subtract 7: 3x = 15.
2. Divide by 3: x = 5.
3. Check: 3 × 5 + 7 = 22 ✓.

**Answer:** **x = 5**

### E2. Factorising a quadratic

**Difficulty:** Easy · **Pattern:** Quadratic Equations

**Problem:** Solve x² − 5x + 6 = 0.

**Solution:**

1. Find two numbers with product 6 and sum −5: −2 and −3.
2. (x − 2)(x − 3) = 0 → x = 2 or x = 3.

**Answer:** **x = 2 or 3**

### E3. Two equations by substitution

**Difficulty:** Medium · **Pattern:** Linear Equations

**Problem:** Solve 2x + 3y = 13 and 3x − y = 3.

**Solution:**

1. From the second: y = 3x − 3.
2. Substitute: 2x + 3(3x − 3) = 13 → 11x − 9 = 13 → x = 2.
3. y = 3 × 2 − 3 = 3.
4. Check: 4 + 9 = 13 ✓; 6 − 3 = 3 ✓.

**Answer:** **x = 2, y = 3**

### E4. Two-digit number

**Difficulty:** Medium · **Pattern:** Two-digit numbers

**Problem:** The sum of the digits of a two-digit number is 9. When the digits are reversed, the number increases by 27. Find the number.

**Solution:**

1. Number = 10a + b; reversed = 10b + a.
2. Increase = 9(b − a) = 27 → b − a = 3.
3. a + b = 9 → b = 6, a = 3.
4. Number = 36; reversed 63 = 36 + 27 ✓.

**Answer:** **36**

### E5. Quadratic formula, sum and product

**Difficulty:** Medium · **Pattern:** Quadratic Equations

**Problem:** Solve 2x² − 7x + 3 = 0 and verify the sum and product of the roots.

**Solution:**

1. a = 2, b = −7, c = 3. D = 49 − 24 = 25.
2. x = (7 ± 5)/4 → x = 3 or x = 1/2.
3. Sum = 3.5 = −b/a = 7/2 ✓. Product = 1.5 = c/a = 3/2 ✓.

**Answer:** **x = 3 or 1/2**

### E6. Using identities

**Difficulty:** Medium · **Pattern:** Algebraic Identities

**Problem:** If a + b = 7 and ab = 12, find a² + b² and a³ + b³.

**Solution:**

1. a² + b² = (a + b)² − 2ab = 49 − 24 = 25.
2. a³ + b³ = (a + b)³ − 3ab(a + b) = 343 − 3 × 12 × 7 = 343 − 252 = 91.
3. Check: a, b are 3 and 4 → 9 + 16 = 25 ✓; 27 + 64 = 91 ✓.

**Answer:** a² + b² = **25**, a³ + b³ = **91**

### E7. Linear inequality

**Difficulty:** Medium · **Pattern:** Inequalities

**Problem:** Solve 3 − 2x > 7.

**Solution:**

1. Subtract 3: −2x > 4.
2. Divide by −2 and reverse the sign: x < −2.
3. Check with x = −3: 3 + 6 = 9 > 7 ✓.

**Answer:** **x < −2**

### E8. x + 1/x

**Difficulty:** Hard · **Pattern:** Algebraic Identities

**Problem:** If x + 1/x = 3, find x² + 1/x² and x³ + 1/x³.

**Solution:**

1. Square: x² + 2 + 1/x² = 9 → x² + 1/x² = 7.
2. Cube: x³ + 1/x³ + 3(x + 1/x) = 27 → x³ + 1/x³ = 27 − 9 = 18.

**Answer:** **7** and **18**

### E9. Quadratic and absolute-value inequalities

**Difficulty:** Hard · **Pattern:** Inequalities

**Problem:** Solve (a) x² − 5x + 6 < 0 and (b) |x − 3| ≤ 2.

**Solution:**

1. (a) (x − 2)(x − 3) < 0 → negative between the roots → 2 < x < 3.
2. (b) −2 ≤ x − 3 ≤ 2 → 1 ≤ x ≤ 5.

**Answer:** (a) **2 < x < 3** (b) **1 ≤ x ≤ 5**

### E10. Comparing roots

**Difficulty:** Hard · **Pattern:** Comparing roots

**Problem:** I. x² − 7x + 12 = 0; II. y² − 9y + 20 = 0. What is the relationship between x and y?

**Solution:**

1. I: (x − 3)(x − 4) = 0 → x = 3 or 4.
2. II: (y − 4)(y − 5) = 0 → y = 4 or 5.
3. Pairs: (3, 4) <, (3, 5) <, (4, 4) =, (4, 5) <.
4. x is never greater than y, and equality is possible → x ≤ y.

**Answer:** **x ≤ y**
