# One Word Substitution

## Concept

One-word substitution replaces a phrase or description with a single precise word: "a person who can speak many languages" → **polyglot**. Questions give the description and ask for the word.

Many of these words are built from Greek and Latin roots, so learning a few roots unlocks whole families: *omni-* (all) → omnipotent, omniscient, omnipresent; *-cide* (killing) → homicide, suicide, genocide.

## Rules

### Useful roots

| Root | Meaning | Words |
|------|---------|-------|
| omni- | all | omnipotent (all-powerful), omniscient (all-knowing), omnipresent (present everywhere), omnivorous (eats all kinds of food) |
| -cide | killing | homicide (a person), suicide (oneself), patricide (father), matricide (mother), fratricide (brother), regicide (king), infanticide (infant), genocide (a whole race or group) |
| -phobia | fear | claustrophobia (closed spaces), hydrophobia (water), acrophobia (heights) |
| -ologist | one who studies | ornithologist (birds), anthropologist (humankind), archaeologist (ancient remains) |
| -cracy | rule | democracy (by the people), autocracy (by one person), bureaucracy (by officials) |
| -vorous | eating | carnivorous (flesh), herbivorous (plants), omnivorous (both) |
| poly- / mono- | many / one | polyglot (many languages), monotheism (belief in one God), monogamy (one spouse) |
| bio- / auto- | life / self | biography (life story by another), autobiography (written by oneself) |

## Solving Approach

1. Identify the key idea in the description (person who…, fear of…, killing of…, study of…).
2. Map the key idea to a root.
3. Check the option against the whole description — similar words differ in detail (*epidemic* vs *pandemic*, *legible* vs *eligible*).

## Common Mistakes

- Confusing near-pairs: legible/eligible, epidemic/pandemic, amateur/novice, biography/autobiography.
- Choosing a word that matches only part of the description.

## Placement Tips

- Learn words by root families — one root gives several answers.
- Review the table regularly; these questions reward memory more than reasoning.

## Key Takeaways

- Roots (omni-, -cide, -phobia, -ologist, -cracy, -vorous) unlock word families.
- Read the whole description; near-synonyms differ in detail.
