# Reading Comprehension

## Concept

Reading comprehension (RC) gives a passage followed by questions. It tests whether you can find stated information, understand the author's main point, draw reasonable inferences, and interpret words in context — under time pressure.

The core rule: **answer from the passage, not from your own knowledge or opinions.** An option can be true in real life and still be wrong if the passage does not support it.

## Rules

### Question types

| Type | Asks | How to answer |
|------|------|---------------|
| Main idea / purpose | What is the passage mainly about? | Combine the topic and the author's point; avoid options that cover only one paragraph |
| Detail | According to the passage, what…? | Find the sentence that states it; match the meaning, not the exact words |
| Inference | It can be inferred that… | Choose what **must** follow from the text — one small logical step, not a leap |
| Vocabulary in context | The word "X" most nearly means… | Replace the word with each option and reread the sentence |
| Tone / attitude | The author's tone is… | Look at adjectives and verbs: neutral, critical, supportive, concerned |
| Title | The best title is… | Must fit the whole passage and its main point |

### Wrong-answer patterns

- **Too broad / too narrow:** covers more than the passage, or just one detail.
- **Extreme words:** *always, never, all, only* — rarely supported.
- **True but irrelevant:** a real-world fact the passage does not mention.
- **Distortion:** uses words from the passage but changes the meaning.
- **Opposite:** reverses what the passage says.

## Solving Approach

1. **Skim the passage** for structure: what each paragraph does (introduces, explains, contrasts, concludes).
2. Note the **main idea** and the author's **attitude** in one line each.
3. Read each question; go back to the relevant lines for detail and vocabulary questions.
4. Eliminate options using the wrong-answer patterns.
5. For inference questions, choose the option that the passage makes **certain or nearly certain**.

## Problem Patterns

### Pattern 1: Main idea

The correct option includes **both** the topic and the author's point. If a passage explains a problem and recommends a solution, the main idea mentions both.

### Pattern 2: Detail

Locate the exact sentence. Paraphrased options are normal; distorted ones change a key word (*some → all*, *may → will*).

### Pattern 3: Inference

Stay close to the text. "Sleep strengthens memories" supports "a student who skips sleep after studying will probably remember less", but not "students who sleep more always score higher".

### Pattern 4: Vocabulary in context

The common meaning of a word may not be the meaning in the passage. Always substitute the option back into the sentence.

## Common Mistakes

- Using outside knowledge.
- Choosing options with extreme words.
- Picking a main idea that matches only the first paragraph.
- Answering vocabulary questions from the dictionary meaning without rereading the sentence.

## Placement Tips

- Read the questions' types before re-reading — detail questions can be answered by scanning.
- Spend about one-third of RC time reading and two-thirds answering.
- If a passage is very long or technical, do other questions first and return to it.

## Key Takeaways

- Answer only from the passage.
- Know the six question types and the five wrong-answer patterns.
- Main idea = topic + point; inference = one small step; vocabulary = meaning in context.
