# Conjunctions

## Concept

A **conjunction** joins words, phrases or clauses and shows the **logical relationship** between them: addition (*and*), contrast (*but, although*), cause (*because*), condition (*if, unless*), purpose (*so that*), time (*when, until*).

Two skills are tested:

1. **Choosing the conjunction whose logic fits** the two ideas.
2. **Using fixed pairs correctly** (*no sooner … than*, *hardly … when*, *not only … but also*) and avoiding doubled conjunctions (*although … but*).

## Rules

### Types

| Type | Conjunctions | Example |
|------|--------------|---------|
| Coordinating (join equal parts) | for, and, nor, but, or, yet, so (FANBOYS) | She was tired, **but** she finished the work. |
| Subordinating (join a dependent clause) | because, since, although, though, unless, if, when, while, until, so that, lest | I stayed home **because** it was raining. |
| Correlative (pairs) | either…or, neither…nor, both…and, not only…but also, whether…or | **Not only** is she clever **but also** hard-working. |

### Choosing by logic

| Relationship | Use |
|--------------|-----|
| Addition | and, both…and, not only…but also |
| Contrast | but, yet, although, though, while, whereas |
| Cause | because, since, as |
| Result | so, therefore (adverb) |
| Condition | if, unless (= if not), provided that |
| Alternative / warning | or, otherwise ("Hurry up, **or** you will miss the bus") |
| Purpose | so that, lest (= so that … not) |

### Fixed pairs

| Correct | Incorrect |
|---------|-----------|
| No sooner … **than** | no sooner … then / when |
| Hardly / Scarcely … **when** | hardly … than |
| Not only … **but also** | not only … and also |
| Both … **and** | both … as well as |
| Neither … **nor** | neither … or |
| Either … **or** | either … nor |
| Lest … **should** | lest … should not (double negative) |
| Such … **that** / So … **that** | such … so |

Inversion: when *no sooner, hardly, scarcely* start the sentence, the verb comes before the subject: "No sooner **had he** arrived than it started to rain."

### Do not double up

- "**Although** he tried hard, **but** he failed" ✗ → "Although he tried hard, he failed" ✓.
- "**Because** it rained, **so** we stayed in" ✗ → "Because it rained, we stayed in" ✓.
- "**Unless** you do **not** work hard" ✗ — *unless* already means *if not*.

### Parallel structure with correlatives

The parts after each half of a pair must have the same form:
"She is not only **intelligent** but also **hard-working**" ✓ (adjective + adjective).
"She not only sings but also **a dancer**" ✗ → "…but also **dances**" ✓.

## Solving Approach

1. Read both parts and name their relationship (contrast? cause? condition?).
2. Pick a conjunction with that logic.
3. If the sentence has a first half of a pair, complete the pair correctly.
4. Check for doubled conjunctions and double negatives.

## Common Mistakes

- *Although … but*, *because … so*.
- *No sooner … then*, *hardly … than*.
- *Unless … not*, *lest … not*.
- Breaking parallel structure after *not only … but also*, *either … or*.

## Placement Tips

- Fixed pairs are among the most frequently tested items in error spotting — memorise the table.
- For fill-in-the-blank conjunctions, decide whether the second idea agrees with or contradicts the first; that eliminates half the options.

## Key Takeaways

- Choose the conjunction whose logic (addition, contrast, cause, condition, purpose) fits.
- No sooner … than; hardly/scarcely … when; not only … but also; lest … should.
- Never use two conjunctions for one link (although … but).
- Keep parallel forms after correlative pairs.
