# Sentence Completion

## Concept

In sentence completion, the first part of a sentence is given and you choose the **phrase or clause** that completes it logically and grammatically. It differs from [Fill in the Blanks](../fill-in-the-blanks/content.md) in scale: you judge a whole idea, not a single word.

Two checks decide the answer:

1. **Logic** — does the completion follow from the opening, given its connecting word (*although, since, if, despite, therefore*)?
2. **Grammar** — does it fit the structure the opening sets up (conditional forms, fixed pairs, parallel forms)?

## Rules

### Logic signals in the opening

| Opening word | Completion must… | Example |
|--------------|------------------|---------|
| Since / because / as | give a **result** of the reason | Since it was raining heavily, **the match was postponed**. |
| Although / though / despite | **contrast** with the expected result | Although she studied hard, **she could not clear the exam**. |
| If (real condition) | give the **consequence** | If you heat ice, **it melts**. |
| Therefore / so / hence | give a **consequence** | The roads were slippery; **therefore, drivers were asked to slow down**. |
| However / but | give a **contrast** | |

### Grammar patterns the opening fixes

| Opening | Completion form |
|---------|-----------------|
| Not only did … | but (subject) also … |
| No sooner had … | than … |
| Hardly / Scarcely had … | when … |
| The more … | the more / the better … |
| If + past perfect (third conditional) | would have + V3 |
| Would have + V3 (main clause) | if + past perfect |

## Solving Approach

1. Read the opening and underline the connecting word.
2. Predict the **kind** of completion (result, contrast, consequence).
3. Eliminate options with the wrong logic.
4. Eliminate options with grammar that clashes with the opening (tense, fixed pair).
5. Read the full sentence with your choice.

## Common Mistakes

- Choosing an option that is true but does not follow from the opening.
- Ignoring the contrast word and picking the "expected" result after *although*.
- Mismatching conditional tenses ("would have caught … if she leaves").
- Breaking fixed pairs (*no sooner … when*).

## Placement Tips

- The connecting word decides most questions in seconds.
- When two options both make sense, check the grammar pattern the opening requires.

## Key Takeaways

- Identify the logical link: result, contrast, condition, consequence.
- Match the grammar pattern the opening sets: conditionals, fixed pairs, "the more … the more".
- Read the completed sentence in full before choosing.
