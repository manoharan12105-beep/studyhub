# Common Mistakes

The errors that cost the most marks across Aptitude, grouped by section. Each line states the mistake and the fix.

## Quantitative Aptitude

### Bases and percentages

- Using the wrong base — **fix:** the base is the number after *of* or *than*.
- Adding successive percentages (+20% then −20% ≠ 0) — **fix:** multiply factors or use a + b + ab/100.
- Reversing a change with the same percentage (a 20% cut needs a 25% rise to recover).
- Profit % on SP — **fix:** profit and loss on CP; discount on MP.
- Adding successive discounts (20% + 10% ≠ 30%; it is 28%).
- Assuming equal % gain and loss on the same SP cancel (it is always a loss).
- Forgetting invalid votes when converting valid votes to total votes.

### Number system

- Calling 1 prime; forgetting 2 is prime.
- Testing divisibility by 12 as 2 × 6 (not co-prime) — **fix:** use 3 × 4.
- Using HCF × LCM = product for three numbers.
- Unit digit when the power mod 4 = 0 — **fix:** take the 4th term of the cycle.
- Counting trailing zeros with only ⌊n/5⌋.

### Ratios, averages, ages, mixtures

- Joining ratios without matching the common term.
- Averaging averages of unequal groups — **fix:** weight by group size.
- Shifting only one person's age by t years.
- Swapping the alligation differences — **fix:** cheaper takes (d − m).
- Subtracting replacement quantities linearly — **fix:** x(1 − y/x)ⁿ.

### Interest

- Using SI formulas for CI questions.
- Changing the rate but not the periods for half-yearly compounding.
- Using the 2-year CI − SI formula for 3 years.
- Reporting the amount when interest is asked (or vice versa).

### Work and motion

- Adding times instead of rates.
- Treating "x% more efficient" as "x% less time".
- Forgetting the leak or outlet is negative.
- Mixing km/h with metres and seconds.
- Simple average of two speeds for equal distances — **fix:** 2xy/(x + y).
- Forgetting the train's own length or the platform/other train's length.
- Adding race margins (A beats C by 19 m, not 20 m).

### Counting, probability, algebra, geometry

- Using permutations for teams or combinations for rankings.
- Letting 0 lead a number.
- Forgetting repeated letters (BANANA: divide by 3! 2!).
- n! instead of (n − 1)! for circles.
- Drawing without replacement but multiplying unchanged probabilities.
- Reading odds as probability (odds in favour 3 : 5 → 3/8, not 3/5).
- Sum of roots as b/a — **fix:** −b/a.
- Not flipping an inequality after multiplying by a negative.
- Using the side ratio, not its square, for areas of similar triangles.
- Using diameter as radius; slant height in a cone's volume.

### Data interpretation

- Ignoring units (thousands, lakhs, crores).
- Confusing absolute increase with percentage increase.
- Mixing degrees and percentages in pie charts (1% = 3.6°).

## Logical Reasoning

- Number series: accepting a rule that fits only the first few terms.
- Alphabet: off-by-one counting; forgetting the Z → A wrap-around.
- Coding: trusting a rule from one letter without checking the others.
- Blood relations: **inferring gender from a name**; treating "only son" as "only child".
- Directions: turning relative to the page instead of the person's facing; forgetting morning shadows point west.
- Ranking: forgetting the −1; subtracting positions measured from different ends; missing the overlap case.
- Analogy: vague relationships; reversing the direction.
- Odd one out: choosing for a cosmetic reason when a meaningful property exists.
- Syllogisms: using real-world knowledge; treating "some" as "some but not all"; reversing "All A are B"; missing either–or pairs.
- Statement questions: accepting conclusions with *only, all, always*; confusing assumptions with conclusions; reading the first statement as the cause.
- Seating: facing the centre makes right = anticlockwise; not checking that the arrangement is unique.
- Puzzles: starting with negative clues; skipping the final check of all clues.
- Data sufficiency: using statement I while judging statement II alone; combining when one alone is enough; missing hidden signs (x² = 16 → ±4).
- Clocks: treating the hour hand as fixed; counting 24 coincidences a day (it is 22).
- Calendars: treating 1900 as a leap year; adding a leap day for a February outside the period.
- Venn: forgetting to add back the centre in the three-set formula; confusing "exactly two" and "at least two".

## Verbal Ability

- Matching the verb to the nearest noun ("The box of pens **are**") — **fix:** find the true subject.
- Plural verbs with *each, every, neither, the number of, news, furniture*.
- Present perfect with *yesterday, ago, last year*; "since five years" — **fix:** "for five years".
- Continuous forms of stative verbs ("I am knowing").
- *Will* in future time clauses ("when he will come").
- *A/an* by spelling instead of sound ("a hour", "an university").
- *Discuss about, reach to, senior than, prefer than, different than*.
- *Between you and I*; *myself* as a polite *me*; *their* for a singular company.
- *Although … but*; *unless … not*; *no sooner … then*; *hardly … than*.
- Changing the tense when converting to the passive.
- Keeping question word order in reported questions.
- Redundancy: *return back, repeat again, more better, most cleverest*.
- Picking the synonym in antonym questions (and vice versa).
- Choosing literal meanings for idioms.
- In para jumbles, starting with a sentence that begins with a pronoun or connective.
- In RC, using outside knowledge or choosing options with extreme words.
