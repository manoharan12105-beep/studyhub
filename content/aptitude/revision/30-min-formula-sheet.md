# Formulas

Only the formulas that come up again and again. Scan, don't study.

## Arithmetic

```text
% change     = (New − Old)/Old × 100
a% then b%   = a + b + ab/100
r% more      → r/(100+r) × 100 % less
Profit%      = Profit/CP × 100
Discount%    = Discount/MP × 100
SP           = CP × (100 ± r)/100
MP/CP        = (100 + P%)/(100 − D%)
Same SP, ±x% → loss x²/100 %
Share in a:b = a/(a+b) × total
Average      = Sum/n
Even spacing → (first + last)/2
Alligation   = (d − m) : (m − c)
```

## Interest

```text
SI           = PRT/100
k times (SI) → RT = 100(k − 1)
CI amount    = P(1 + R/100)ⁿ
CI − SI      = P(R/100)²  (2 years)
Half-yearly  → R/2 and 2n periods
1.1² = 1.21   1.1³ = 1.331   1.2² = 1.44
```

## Work and motion

```text
Together     = ab/(a + b)
Total work   = LCM of times
M₁D₁H₁/W₁    = M₂D₂H₂/W₂
Leak empties = ab/(b − a)
km/h → m/s   × 5/18
Avg speed    = 2xy/(x + y)  (equal distances)
Relative     = S₁ + S₂ (opposite), S₁ − S₂ (same)
Train        = (L₁ + L₂)/relative speed
Boat         u = (D + U)/2,  stream v = (D − U)/2
```

## Numbers and counting

```text
Factors of pᵃqᵇ   = (a + 1)(b + 1)
Zeros in n!       = ⌊n/5⌋ + ⌊n/25⌋ + …
HCF × LCM         = a × b  (two numbers)
ⁿPᵣ               = n!/(n − r)!
ⁿCᵣ               = n!/(r!(n − r)!)
Circle            = (n − 1)!
Identical items   = n!/(p! q!)
P(at least one)   = 1 − P(none)
```

## Algebra and geometry

```text
Roots         = [−b ± √(b² − 4ac)]/2a
Sum, product  = −b/a, c/a
(a + b)²      = a² + 2ab + b²
a² − b²       = (a + b)(a − b)
x + 1/x = k   → x² + 1/x² = k² − 2
Polygon sum   = (n − 2) × 180°
Exterior      = 360°/n
Diagonals     = n(n − 3)/2
Similar areas = (side ratio)²
Triplets      3-4-5, 5-12-13, 8-15-17, 7-24-25
```

## Mensuration

```text
Circle      πr², 2πr
Cylinder    πr²h, CSA 2πrh
Cone        ⅓πr²h, CSA πrl, l = √(r² + h²)
Sphere      4/3 πr³, 4πr²
Hemisphere  TSA 3πr²
Cube        a³, 6a²
Cuboid      lbh, diagonal √(l² + b² + h²)
```
