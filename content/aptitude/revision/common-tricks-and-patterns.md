# Tricks and Patterns

How to recognise each common question type from its wording, and the first move to make. Use it to train fast pattern recognition.

## Quantitative Aptitude

| If the question says… | It is… | First move |
|------------------------|--------|------------|
| "greatest number that divides … leaving the same remainder" | HCF of differences | Subtract the numbers pairwise |
| "least number which when divided by … leaves remainder r" | LCM + r | Find the LCM |
| "bells ring together / lights flash together" | LCM | LCM of the intervals |
| "unit digit of" a large power | Unit-digit cycle | Power mod 4 |
| "remainder when 2²⁵⁶ is divided by 17" | Power cycle / Fermat | Find a power ≡ ±1 |
| "after an increase of r%, it became X; find the original" | Reverse percentage | Divide by (1 + r/100) |
| "A is r% more than B; B is what % less than A" | Base change | r/(100 + r) × 100 |
| "price rises; by how much should consumption fall" | Expenditure constant | r/(100 + r) × 100 |
| "winner got x% and won by n votes" | Election margin | Margin% × valid votes = n |
| "fails by a marks … passes by b marks" | Pass marks | Equate the two pass-mark expressions |
| "marked … above cost, discount …" | Markup and discount | Multiply factors |
| "sold two items at the same price, x% gain and x% loss" | Same SP | x²/100 % loss |
| "uses a false weight" | Dishonest dealer | (True − False)/False × 100 |
| "CP of x articles = SP of y articles" | Article ratio | (x − y)/y × 100 |
| "incomes in ratio … expenditures in ratio … savings" | Income–expenditure | ax − cy = savings, two equations |
| "teacher's age included, average rises by" | New member | Old avg + new count × rise |
| "in the 17th innings scored … average increased by" | Innings average | Score − old innings × rise |
| "in what ratio must … be mixed to get" | Alligation | Draw the cross |
| "removed and replaced with water, n times" | Repeated replacement | x(1 − y/x)ⁿ |
| "sum doubles / triples in n years" (SI) | Linear growth | RT = 100(k − 1) |
| "difference between CI and SI for 2 years" | CI − SI | P(R/100)² |
| "amounts to A₁ in 2 years and A₂ in 3 years" (CI) | Consecutive amounts | R = (A₂ − A₁)/A₁ |
| "A can do in x days, B in y days, together" | Rates add | LCM method |
| "work together for d days, then A leaves" | Partial work | Subtract work done, continue with remaining rate |
| "alternate days" | Cycle work | Work per 2-day cycle, finish remainder |
| "pipe fills … leak empties" | Signed rates | Net rate |
| "earn ₹… together; find A's share" | Work and wages | Ratio of work done |
| "crosses a pole / platform / another train" | Train lengths | Distance = own length (+ other length) |
| "downstream … upstream" | Boats | u = (D + U)/2, v = (D − U)/2 |
| "A beats B by x m" | Race ratio | L : (L − x) |
| "goes at x, returns at y" | Equal distances | 2xy/(x + y) |
| "arranged so that vowels are together" | Glue | Treat vowels as one block |
| "no two … together" | Gap method | Arrange others, choose gaps |
| "committee … at least one woman" | Complement | Total − no women |
| "round table" | Circular | (n − 1)! |
| "probability at least one" | Complement | 1 − P(none) |
| "x and y relationship" from two quadratics | Root comparison | Solve both, compare all pairs |
| "angles in the ratio" | Angle sum | Parts share 180° or (n − 2)180° |
| "melted and recast" | Volume conserved | Equate volumes |
| "each side increased by r%" (area) | Successive % | r + r + r²/100 |

## Logical Reasoning

| If the question says… | It is… | First move |
|------------------------|--------|------------|
| Numbers that grow slowly | Difference series | Write first differences |
| Numbers that grow fast | Ratio / power series | Check ratios, squares, cubes |
| Numbers that go up and down | Alternating series | Split odd and even positions |
| "find the wrong number" | Wrong-term series | Find the rule from the majority |
| Letter groups (ABD, DEG …) | Group series | Track each position separately |
| "If CAT is coded as …" | Letter coding | Compute position differences |
| "If DELHI = 73541 …" | Substitution code | Map letter → digit |
| "'sky is blue' is 'ta na pa' …" | Sentence coding | Common word ↔ common code |
| "Pointing to a photograph …" | Blood relation | Replace phrases inside-out |
| "P + Q means P is the mother of Q" | Coded relation | Translate symbols, draw tree |
| "walks … turns left …" | Direction | Track (x, y) |
| "shadow falls to his left in the morning" | Shadow | Morning shadow → west |
| "x-th from left and y-th from right" | Ranking | L + R − 1 |
| "they interchange positions" | Swap | New position = other's old position |
| "minimum number of people in the queue" | Overlap case | Try both orders |
| "A : B :: C : ?" | Analogy | Name the relationship precisely |
| "which belongs to the same group" | Classification | Most specific shared property |
| "find the odd one out" | Misfit | Property shared by all but one |
| "All/Some/No … Conclusions" | Syllogism | Draw diagrams; try to break each conclusion |
| "is a possibility" | Possibility | True in at least one valid diagram? |
| "Statement … Conclusions" | Conclusion | Is it forced? Watch extreme words |
| "Statement … Assumptions" | Assumption | Negation test |
| "I. … II. …" two events | Cause and effect | Which explains which? |
| "sit around a circular table facing the centre" | Circular seating | Right = anticlockwise |
| "live on different floors" | Floor puzzle | Column, bottom = floor 1 |
| "each has a different … and a different …" | Grid puzzle | Elimination grid |
| "Statements I and II … is sufficient" | Data sufficiency | I alone, II alone, then together |
| "angle between the hands at" | Clock angle | \|30H − 5.5M\| |
| "mirror image of the clock" | Mirror time | 11:60 − time |
| "what day of the week was" | Calendar | Count odd days |
| "calendar of year X will repeat" | Calendar repeat | 28 (leap), 6 or 11 years |
| "best represents the relationship" | Venn diagram | Decide each pair |

## Verbal Ability

| If the question says… | It is… | First move |
|------------------------|--------|------------|
| "Choose the correct verb" | Agreement / tense | Find the true subject and time signal |
| "Find the part that has an error" | Error spotting | Run the checklist |
| "Replace the bold part … No improvement" | Sentence correction | Name the error type, then eliminate |
| "Change into passive voice" | Voice | Keep the tense; object → subject |
| "Change into indirect speech" | Reported speech | Reporting verb, backshift, time words |
| One blank in a sentence | Fill in the blank | Find the clue word |
| Two blanks | Double blank | Solve the easier blank first |
| "Complete the sentence" | Sentence completion | Read the connective; predict the kind of ending |
| "Choose the word closest in meaning" | Synonym | Define first; reject antonyms |
| "Choose the word opposite in meaning" | Antonym | Define first; reject synonyms |
| "A person who …" | One word substitution | Find the root |
| Expression in bold, meaning asked | Idiom | Non-literal meaning |
| Sentences P, Q, R, S to arrange | Para jumble | Opening + mandatory pair |
| Passage with questions | Reading comprehension | Identify question type, go back to the text |
