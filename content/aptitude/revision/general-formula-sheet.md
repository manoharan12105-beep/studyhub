## Number System

```text
Number of factors of pᵃ·qᵇ·rᶜ      = (a+1)(b+1)(c+1)
Sum of factors                     = [(pᵃ⁺¹−1)/(p−1)] × [(qᵇ⁺¹−1)/(q−1)] × …
Trailing zeros in n!               = ⌊n/5⌋ + ⌊n/25⌋ + ⌊n/125⌋ + …
HCF × LCM                          = product of the two numbers (two numbers only)
HCF of fractions                   = HCF(numerators) / LCM(denominators)
LCM of fractions                   = LCM(numerators) / HCF(denominators)
Dividend                           = Divisor × Quotient + Remainder
Fermat: p prime, p ∤ a             → aᵖ⁻¹ leaves remainder 1 when divided by p
(x+1)ⁿ ÷ x                         → remainder 1
(x−1)ⁿ ÷ x                         → remainder 1 (n even), x−1 (n odd)
aⁿ − bⁿ divisible by a − b (any n), by a + b (n even); aⁿ + bⁿ by a + b (n odd)
Unit digit of aⁿ                   → cycle of a's last digit, position n mod 4 (0 → 4th)
```

| Remainder pattern | Answer |
|-------------------|--------|
| Largest number leaving the same remainder | HCF of the differences |
| Largest number leaving remainders r₁, r₂ | HCF(a − r₁, b − r₂) |
| Smallest number leaving remainder r for each divisor | LCM + r |
| Smallest number where divisor − remainder = k for all | LCM − k |

## Percentages

```text
x% of y                     = xy/100
% change                    = (New − Old)/Old × 100
A is r% more than B         → B is r/(100+r) × 100 % less than A
A is r% less than B         → B is r/(100−r) × 100 % more than A
Successive changes a%, b%   = a + b + ab/100   (decreases negative)
Growth / depreciation       = P(1 ± r/100)ⁿ
Price ↑ r%, same spending   → consumption ↓ r/(100+r) × 100 %
Price ↓ r%, same spending   → consumption ↑ r/(100−r) × 100 %
```

## Profit, Loss and Discount

```text
Profit% = (SP − CP)/CP × 100           Loss% = (CP − SP)/CP × 100
SP = CP × (100 ± P%)/100               CP = SP × 100/(100 ± P%)
Discount% = (MP − SP)/MP × 100         SP = MP × (100 − d%)/100
MP/CP = (100 + Profit%)/(100 − Discount%)
Successive discounts d₁, d₂ = d₁ + d₂ − d₁d₂/100
Same SP, x% gain on one, x% loss on other → net loss x²/100 %
False weight gain% = (True − False)/False × 100
Buy x get y free → discount = y/(x+y) × 100
CP of x articles = SP of y articles → profit% = (x − y)/y × 100
```

## Ratio and Proportion

```text
Share of A in a : b        = a/(a+b) × Total
A:B = a:b, B:C = c:d       → A:B:C = ac : bc : bd
a : b = c : d              ⇔ ad = bc
Mean proportional of a, b  = √(ab)
Third proportional to a, b = b²/a
Fourth proportional        = bc/a
Duplicate a² : b²; sub-duplicate √a : √b; triplicate a³ : b³
Direct: y₁/x₁ = y₂/x₂      Inverse: x₁y₁ = x₂y₂
```

## Averages

```text
Average = Sum/n                   Sum = Average × n
Evenly spaced numbers             = (first + last)/2
First n natural numbers           = (n+1)/2
First n odd numbers               = n;     first n even numbers = n + 1
Weighted average                  = Σnᵢaᵢ / Σnᵢ
New member (average rises by d)   = old average + (new count) × d
Replacement                       new − old = n × (change in average)
Corrected average                 = wrong average + (correct − wrong)/n
```

## Simple Interest

```text
SI = PRT/100              A = P + SI = P(1 + RT/100)
P = 100·SI/(RT)    R = 100·SI/(PT)    T = 100·SI/(PR)
Sum becomes k times: RT = 100(k − 1)
SI for (T₂ − T₁) years = A₂ − A₁
Changing rates: SI = P × Σ(Rᵢ·Tᵢ)/100
```

## Compound Interest

```text
A = P(1 + R/100)ⁿ          CI = A − P
Half-yearly: R/2, 2n periods      Quarterly: R/4, 4n periods
Different rates: A = P(1 + R₁/100)(1 + R₂/100)…
Fractional years n + f: A = P(1 + R/100)ⁿ (1 + fR/100)
CI − SI (2 years) = P(R/100)²
CI − SI (3 years) = P(R/100)²(3 + R/100)
Consecutive amounts: R = (A₂ − A₁)/A₁ × 100
k times in n years → kᵐ times in mn years
Equal instalments x: P = x/(1+r) + x/(1+r)² + … + x/(1+r)ⁿ, r = R/100
```

Growth factors: 1.1² = 1.21 · 1.1³ = 1.331 · 1.05² = 1.1025 · 1.05³ = 1.157625 · 1.2² = 1.44 · 1.2³ = 1.728

## Time and Work

```text
Rate = 1/time; rates add
Together (two): ab/(a + b)       Together (many): 1/T = Σ 1/aᵢ
Total work = LCM of individual times (units)
M₁D₁H₁/W₁ = M₂D₂H₂/W₂
Efficiency ∝ 1/time
Pipes: inlets +, outlets −; leak alone = ab/(b − a)
Wages ∝ work done = efficiency × days
```

## Time, Speed and Distance

```text
D = S × T             km/h × 5/18 = m/s         m/s × 18/5 = km/h
Average speed (equal distances) = 2xy/(x + y)
Relative speed: opposite S₁ + S₂; same direction |S₁ − S₂|
After meeting, times t₁, t₂ → S₁/S₂ = √(t₂/t₁)
Train crossing: pole L/S; platform (L + P)/S; train (L₁ + L₂)/(S₁ ± S₂)
Boats: D = u + v, U = u − v; u = (D + U)/2, v = (D − U)/2
Races: A beats B by x in L → S_A : S_B = L : (L − x)
Circular track: first meeting = length/(relative speed); at start = LCM of lap times
```

## Algebra

```text
ax² + bx + c = 0: x = [−b ± √(b² − 4ac)]/2a;  D = b² − 4ac
Sum of roots = −b/a;  product = c/a;  equation: x² − (sum)x + product = 0
(a ± b)² = a² ± 2ab + b²            a² − b² = (a + b)(a − b)
(a + b)³ = a³ + b³ + 3ab(a + b)      (a − b)³ = a³ − b³ − 3ab(a − b)
a³ ± b³ = (a ± b)(a² ∓ ab + b²)
a + b + c = 0 ⇒ a³ + b³ + c³ = 3abc
x + 1/x = k ⇒ x² + 1/x² = k² − 2;  x³ + 1/x³ = k³ − 3k
(x − a)(x − b) < 0 ⇒ a < x < b;  > 0 ⇒ x < a or x > b
|x| < a ⇒ −a < x < a
```

## Geometry

